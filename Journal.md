Also i made holes in it and this was really challengin part for me, as first lol i added solid instead of removing, then the main challenge was about dimensions, like i though the dimension given in rapbery pi docs about holes to bt M2.7, i though its Diameter is this much and we need to enter radius using dimension tool, so i entered 1.35 lol, then i though doesn't this seems so small so later i got to know we need to enter diameter and not radius
